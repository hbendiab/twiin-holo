La stack en détail pour les questions
BriqueTechnologieCe qu'elle fait, et pourquoi
AgirHolo (holo4-35b) par l'Agents API de H Company, SDK hai-agentsVoit l'écran et décide du prochain clic. Cloud H Company pour le web (navigateur distant), pont local (« holo local desktop ») pour les logiciels du Mac. Commandes et fichiers bloqués, double Échap pour tout arrêter.
ComprendreQwen 3.8 (27B), vision-langage open source, via le routeur Hugging Face (API compatible OpenAI)Lit le texte de l'écran et quelques images, découpe la tâche en étapes, écrit les valeurs attendues et les vérifications. Changeable en une ligne, hébergeable chez le client.
Orchestrern8n, installé sur le posteLe plan est compilé en workflow : un bloc par étape, une branche par entreprise suivie (une cible qui échoue n'arrête pas les autres), un bloc « Vérifier les valeurs » avant chaque écriture. Rejoué et testé avant d'être activé.
ObserverEnregistreur Node + workers Python, OCR du Mac (Vision)Captures et journal de clics, sans touches du clavier. Texte lu en local, e-mails et jetons masqués avant tout envoi.
App MacElectron, serveur Node + ExpressBarre de menus, notifications, jumeaux guides affichés sur l'écran où se passe la tâche (Mac ou moniteur externe), invisible dans ses propres captures.
ExtensionChrome, Manifest V3Bulle sur chaque page, panneau latéral : enregistrer, lancer, voir les automatisations du site.
TéléphonePage mobile + relais sur VercelLe téléphone n'a jamais d'accès direct au Mac : il dépose une demande chiffrée, le Mac l'exécute, l'accès se coupe en un geste.
DonnéesSupabase : Postgres, Auth, règles RLSComptes, tâches, automatisations, exécutions. Chaque entreprise ne voit que ses lignes ; les captures et vidéos restent sur le poste.
VidéosElevenLabs (voix), Remotion (montage en React)Chaque tâche devient une vidéo de formation, aux couleurs de l'entreprise.
SécuritéClés sur le poste uniquementAucune clé dans l'installeur ni dans le dépôt GitHub public ; le mode démo du jury est en lecture seule pour tout ce qui touche au Mac.

Coût mesuré : Holo 0,30 $ / million de tokens en entrée, 2 $ en sortie · 0,01 $ une tâche web, 0,15 $ une tâche sur le Mac · Qwen ≈ 0,002 $ par analyse.
